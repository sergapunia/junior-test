# Первые 90

Рабочая версия: https://pervye-90.vercel.app

Демо для HR и руководителей: кого из новичков на испытательном разобрать на этой неделе. Компания «Форвард» и люди вымышлены.

## Запуск

```bash
npm install
npm test
npm run dev
```

## Отчёт

«Новичок» — сотрудник в первые 90 дней. Каждый третий ушедший не дожил до этого срока, и проблему обычно видят уже по заявлению. Делали для HR и руководителей склада, розницы, опта и офиса.

Сделали «Первые 90»: очередь на неделю по вымышленной выгрузке из Битрикс24. Балл складывается из сорванных шагов адаптации — встреча наставника, блокер, пульс, чек-лист, просрочки, тишина руководителя. Из карточки ставится задача; «шаг выполнен» пересчитывает балл и убирает человека из очереди. Можно смотреть контур своим глазом: HR или руководитель подразделения.

Отказались от живого API Битрикс24 и от «предсказания увольнения»: за 4 часа это была бы декорация. Не рисовали ложный статус «синхронизация онлайн».

Проверили расчёт скриптом и в браузере основной сценарий: Павел Ершов → задача → «шаг выполнен» → балл 64→34, человек выходит из очереди. Проверили фильтр склада и что ссылка открывается.

Не проверяли боевой портал Битрикс24 и не проходили все 18 карточек по одной.

Следующий шаг: читать задачи приёма и чек-листа из Битрикс24 и писать поручение обратно. Увольнение само не запускать.
